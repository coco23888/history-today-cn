> 把维基百科的「历史上的今天」整理成一份**能直接上线用的中文数据集**。
> 6.3 万条 · 366 天全覆盖 · 每条都带分类 / 标签 / 敏感度 / 中国关注度评分 / 精简后文案

维基数据 + 百度节日 → 简体化 → **用 AI 额度逐条清洗、分类、按中国关注度打分** → 开箱可用。
全部本地可跑，除 AI 调用外无外部依赖。

**62,927 条 · 366 天全覆盖 · 100% 已清洗打标 · 每条带分类 / 标签 / 敏感度 / 中国关注度评分**

## 做了什么

原始数据是能拿到的，但**拿到不等于能用** —— 繁体、港式译名、格式脏、没有分类、没有排序、还夹着大量不适合直接展示的表述。
这个项目把它跑通成成品：

| 做的事 | 结果 |
|---|---|
| 🌏 **抓全 366 天**维基日期条目（不逐个请求，**8 次请求**抓完） | 64,891 条原始条目 |
| 🔄 **一键转简体**（OpenCC 迭代到不动点，残留繁体 **0 条**，并清理港式译名与地区用词） | 5.7 MB 简体数据集 |
| 🧩 **合并百度百科中文节日**（带设立由来） | 覆盖 55 天 |
| 🤖 **用 AI 逐条清洗**（SiliconFlow 额度，全量实测 **¥29**） | 62,927 条，**0 失败** |
| 🎯 **按中国关注度打分排序**（1–100 分） | 最值得看的自动排最前 |
| 🏷️ **打标签分类**：10 个分类 + 7 个敏感标签 + 敏感度 0–3 | 每条都有，开箱可筛 |
| ✍️ **言简意赅改写**：删的是表述，不是事件 | 132.1 万字 → **95.9 万字** |
| 👤 **网页复核工具**（可编辑、可标记、实时保存） | 数据采集 → 上线全流程打通 |
| 📄 **剥离世界纪念日**到独立文件（按 277 个国家/地区分组） | 1,983 条 |

原始 wikitext 混用两岸三地译名，例如同一个词会有 `車路士 / 切尔西`、
`碧咸 / 贝克汉姆`、`朗拿度 / 罗纳尔多`、`施丹 / 齐达内` 两三种写法。
转换过程把这些**港式体育译名统一成了大陆通用译名**（原始文本里出现多次的
`車路士`、`樸茨茅夫`、`費格遜`、`阿仙奴`、`祖雲達斯`、`國際米蘭`、`碧咸`、`朗拿度`、`施丹`
在成品里均为 **0 次**），避免同一份数据里两套叫法并存。

## 敏感条目：按需筛选，不用改代码

上面那套标注（`sens` + `tags`）**拿到就能直接用**，无需任何额外处理：

| 你的需要 | 做法 |
|---|---|
| 全部展示 | 直接用（数据已中性化，不含定性词与煽动性表述） |
| 只要最干净的一批 | 取 `sens === 0`（49,550 条，78.7%） |
| 过滤较敏感的 | 按 `sens >= 2` 或按标签筛掉 |
| 单独审一遍 | 打开复核页过一遍，标记结果存 `data/review.json` |
| 完全不展示某类 | 按 `tags` 排除对应分类 |

复核页（`npm run review`）默认只列 AI 拿不准的那 7,095 条，可**直接编辑文案**、标记通过/不展示，**实时保存**。
**整条流程不需要改任何代码。**

## 复现整条管线

前 3 步（抓取 → 解析 → 转简体）的脚本是选源调研时写的，**没有随本仓库发布**。
`data-src/` 里已经有现成的维基原始 wikitext 和解析好的简体数据集，
所以日常只需要跑第 4 步：

```bash
# 1~3. 抓取 / 解析 / 转简体 —— 脚本未随仓库提供
#       已有产物：data-src/维基-历史上的今天离线/_raw/zh/（366 个原始 wikitext）
#                data/wiki-zh-Hans.json（解析并转简体后的结果）

# 4. 合并 + AI + 审计 + 出页
npm run prep         # 合并维基与百度节日，分配稳定 ID
npm run ai:resume    # AI 清洗打标（断点续跑；需要 API Key）
npm run audit        # 8 项数据质量审计
npm run site         # 生成展示页
```

想重抓维基数据，用 MediaWiki API 批量拉 366 个 `M月D日` 条目的 wikitext 即可
（50 个标题一请求，8 次请求抓完，见 `docs` 说明）；解析时注意处理
`-{zh-cn:…;zh-tw:…}-` 简繁转换标记。

## 注意事项（改代码前务必看）

1. **日期键必须零填充 `MM-DD`**。混用 `10-8` 和 `10-08` 会让日期**静默回退**到邻近日期（真实踩过的坑）。三处已归一化，`npm run site` 会断言。
2. **`prep_merge.js` 是从零重建 `merged.json`**。段落修正逻辑在 `src/lib/section_fix.js`，**新增修正必须加进那个共用模块**，否则重跑 `prep` 会把它抹掉。
3. **AI 并发不要超过 20**。实测 60 并发触发 `429 / code 50609` 重试风暴，反而更慢。
4. **不要删/重排 `data/ai/results.jsonl`**（删了就得从头跑）。中断用 `npm run ai:resume`。
5. **`config/.env` 已被 gitignore**，仓库里只有 `.env.example`。别把 Key 提交上去。
6. **`web/index.html` 是 18.5 KB 的空壳**，数据靠 fetch `data.json` —— 必须经 HTTP 访问（`npm run review`）。要双击打开就用 `npm run site:standalone`。
7. 数据授权：维基 **CC BY-SA 4.0 必须署名**；百度数据版权归百度。见 [`NOTICE.md`](NOTICE.md)。
